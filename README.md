# 📈 Stock Price Predictor

A simple machine learning project that predicts future stock prices using historical data with Python. It uses **Linear Regression** and displays a visual comparison between actual and predicted stock prices.

## 🚀 Features

- Fetches historical stock data using the `yfinance` API
- Trains a Linear Regression model on stock closing prices
- Predicts future stock prices (default: next 30 days)
- Visualizes predictions with Matplotlib

## 🛠️ Tech Stack

- Python
- yfinance
- pandas
- scikit-learn
- matplotlib
